| Browser (client) → EdgeOne CDN/static tier | Untrusted client requests for static assets — no user input processed here in Phase 1 |
| Browser (client) → Edge Function (`/api/status`) | Untrusted client request reaches Function runtime; response must never leak the raw secret value |
| Developer machine → npm registry | Package install/upgrade of `edgeone` CLI — supply-chain trust boundary |
