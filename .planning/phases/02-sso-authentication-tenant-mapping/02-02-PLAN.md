<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> /api/status | Untrusted input crosses here: any query string the client appends is ignored for tenant resolution — only the verified session cookie is trusted. |
| Browser (refresh) -> Edge Function | The refreshed request carries only the `session` cookie; no OIDC round-trip re-occurs, so `verifySession` is the sole authority on session validity for every subsequent request (D-06, no server-side store to consult). |
