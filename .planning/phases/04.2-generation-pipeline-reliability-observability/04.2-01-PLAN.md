</objective>

A new top-level async function `fetchWidgetData(widget, account, action, version, env)` placed above `onRequestPost` (near `computeTimeRangeWindow`), containing the EXACT same body currently inside the loop — `computeTimeRangeWindow(widget.timeRange)`, `signTeoRequest({...})` with the same payload shape (`StartTime`/`EndTime`/`MetricNames: [widget.metric]`/`Interval: widget.interval`/`ZoneIds: [account.zoneId]`), the same `try { fetch(...); teoResponse = await res.json(); } catch { return null; }` (Pitfall 6 preserved: `return null` instead of `continue`), the same `if (teoResponse?.Response?.Error) return null;` guard (never forward `Response.Error` — it can contain the ZoneId), and the same final return object shape `{ componentType, title, metric, interval, timeRange, data: teoResponse?.Response?.Data }`.
